01

关于我

一个把硬件当手艺做的工程师。

我做嵌入式开发，工作范围覆盖 MCU 固件、PCB 硬件设计 和 配套上位机工具 三段。习惯从需求一路跟到打样、调试、量产， 不用在软硬件之间反复交接。

固件侧主要用 STM32、沁恒 CH32（RISC-V）和 ESP32 三套平台，裸机和 RTOS 都做， 重点是外设驱动、通信协议栈和低功耗优化。硬件侧画原理图和 PCB， 工具链在 Altium Designer、KiCad、立创EDA 之间按项目切换。

需要的话也会写上位机：串口 / CAN 调试工具、实时数据曲线、测试数据导出， 把调试过程变得省事一点。

  • 现在关注 RISC-V 平台的固件生态、低功耗节点设计
  • 可以合作 从方案到打样的完整硬件项目、存量产品的固件维护
  • 工作方式 先跑通最小系统，再逐步加功能，每一步都可验证

技能栈

MCU 与固件

STM32（F1/F4/H7 系列）、沁恒 CH32（RISC-V 与 M3）、ESP32 三套平台。 裸机与 FreeRTOS 双路线，熟悉外设驱动、中断与 DMA、时钟树配置、Flash 分区与 OTA。

  • STM32
  • CH32V
  • ESP32
  • FreeRTOS
  • 低功耗
  • OTA

硬件设计

原理图、PCB Layout、器件选型与 BOM 整理。从两层板到四层板，兼顾成本与 EMC。

  • Altium
  • KiCad
  • 立创EDA

通信与协议

板级总线到无线链路：串口、CAN、Modbus，以及 BLE / Wi-Fi 的联网方案。

  • CAN
  • Modbus
  • BLE
  • MQTT

上位机与调试工具

用 Python 或 C# 写串口 / CAN 调试工具，做实时数据曲线、参数下发、 日志解析与 CSV / Excel 导出，把重复的调试动作自动化掉。
